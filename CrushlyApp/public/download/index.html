Install in three steps

  1. Wait for the download button above to become available, then tap it once.
  2. When the download finishes, open the file from My Files → Downloads.
  3. If Android asks, allow Install unknown apps for your browser or file manager, then confirm installation. You can revoke that permission afterwards.

Before you install

  • Install only from this page. If the button is unavailable, don’t install an older or partial file.
  • Keep Play Protect on. Holup will never ask for your password, a sign-in code, or card details in a chat.
  • “There was a problem parsing the package” usually means the download was not a complete APK. Delete that file and return to this page rather than retrying it.
