Install in three steps

  1. Tap the download button and wait for it to finish. Use Wi-Fi if you want to save mobile data.
  2. Open My Files → Downloads, then tap Crushly-1.0.2-Android9plus.apk.
  3. If Android asks, allow Install unknown apps for the browser or file manager you are using, then confirm installation. You can revoke that permission afterwards.

Before you install

  • Install only from this page. If a file reaches you any other way, don't open it.
  • Keep Play Protect on, and never switch off your phone's security protections for any app.
  • Crushly will never ask for your password, a code sent to you, or your card details inside a chat. If somebody does, Cut Off and Flag them.
